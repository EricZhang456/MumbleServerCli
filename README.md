# MumbleServerCli

Manage mumble-server from the command line via the Ice interface.

```
Description:
  Control mumble-server via the Ice interface.

Usage:
  mumble-server-cli [command] [options]

Options:
  -?, -h, --help  Show help and usage information
  --version       Show version information

Commands:
  server   Manage virtual servers
  config   Configure virtual servers
  uptime   Get the uptime of Mumble master instance
  version  Show version of Mumble master instance
  user     Manage users on a virtual server
  channel  Manage channels on a virtual server
  msg      Send text messages to channels or users
```
